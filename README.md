## 구현 기능 요약
- `data.js`의 영화 객체 배열을 읽어 `.board` 영역에 카드를 동적으로 렌더링 (`renderCards`)
- 실시간 제목 검색(`input`), 정렬(`change`: 기본순·평점순·최신순·제목순) 동시 연동 (`getView`)
- 검색창 `Escape` 키 입력 시 검색어 초기화 및 전체 목록 복원 (`keydown`)
- `.board` 클릭 이벤트 위임을 통한 찜(`♥`) 토글 및 찜 개수(`#likeCount`) 실시간 카운트
- 검색 결과가 0건일 때 `.is-empty` 클래스와 인접 형제 선택자를 이용한 빈 화면 안내 처리

## 생성형 AI 활용 기록
- **활용 목적**: 11주차 미완성 코드 연결 구조 확인, DOM 동적 렌더링 및 이벤트 처리 개념 이해, 문법 오류 원인 분석
- **주요 질문 및 답변 요약**:
  1. **정적 카드의 동적 전환 (`renderCards`)**: `index.html`에 직접 작성했던 카드 태그를 비우고 `movies.map()`과 템플릿 리터럴을 이용해 `innerHTML`로 생성하는 원리 및 TMDB 포스터 이미지 경로 결합 방법 확인
  2. **검색과 정렬 동시 연동 (`getView`)**: 검색어 필터링(`filter`) 후 선택된 기준(`sortBy`)에 따라 배열을 정렬해 반환하는 함수 설계 및 `input`, `change`, `keydown` 이벤트 연결 구조 확인
  3. **이벤트 위임 및 오류 수정**: 동적으로 생성되는 `.like` 버튼 대신 부모 요소(`.board`)에 클릭 리스너를 등록하는 이유와 `e.target` 판별법, 변수 대소문자 오타 및 CSS 캐시/저장 문제 해결
- **작성 방식**: 안내받은 개념과 구조를 바탕으로 모든 HTML, CSS, JavaScript 코드를 직접 타이핑하여 구현함
